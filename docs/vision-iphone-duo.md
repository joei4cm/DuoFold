# Vision: DuoFold product bar

North-star public UX cues: calm foldable continuity (outer ↔ inner), StandBy-style cover mode, soft materials, fluid Home editing. Inspiration is behavioral/visual only — DuoFold ships original source exclusively.

## Product targets (HyperOS 4 / 18 Fold)

| Cue | DuoFold target |
|---|---|
| Continuity cover→inner | Shared layout model; cover shows focused page, inner adds leading canvas |
| Calm glass / large type | Soft frosted panels, spring motion, refined typography |
| Cover StandBy | Multi-page cover: clock / photo / glance cards |
| Hinge feel | Hinge-linked leaf wipe + page morph |
| Right-edge dock | Premium vertical dock with blur and haptic cues |
| Widgets | First-party glance cards + native AppWidget host |
| Fluid Home editing | Long-press edit mode, drag between dock/grid/pages |

## Hard OS limits (do not fake)

- System Keyguard / AOD chrome
- Stock HyperOS app open/recents choreography
- System Split View (OS multitasking, not launcher)

We win by owning **Home, StandBy, fold continuity, motion, and glance content**.

## Build waves

1. **Motion & materials** — springs, frosted dock/sheets, fold morph
2. **StandBy suite** — clock / photo / glance pages
3. **Editing** — drag, dock swap, page add
4. **Widgets** — native host + first-party cards
5. **HyperOS assist** — shade + optional soft nav (original Assist service)
