# Design notes

Product inspiration may include public foldable UX patterns (dual-pane home, cover standby, glass-like motion). This document is research notes for DuoFold’s original implementation.

## Behavioral ideas

- Right dock + grid home on foldables
- Extra workspace when unfolded
- Soft motion tied to hinge angle
- Cover landscape clock mode
- Optional companion lock UI (never claiming SystemUI replacement)

## Explicit non-goals

- No shared package name or signing identity with other products
- No activation / paywall
- No third-party launcher source in the app module
