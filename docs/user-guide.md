# DuoFold user guide (0.5.0)

1. Install the **release-signed** APK (`./scripts/release-signed.sh`).
2. Open DuoFold, then set it as default Home in system settings (gear → Set as Home).
3. Swipe Home pages horizontally; the last page hosts All apps. Use the apps / settings icons at the top.
4. Unfolded (inner + wide): a leading pane appears beside Home.
5. Optional: Fold animation, Cover StandBy, Lock surface — toggles in Settings.
6. Lock surface appears after system unlock when enabled; it does not replace HyperOS Keyguard.

Widgets, icon packs, and HyperOS gesture ADB assist are not in 0.2 yet.
